ANDROID FIRMWARE EMULATOR

AEmulator

Run supported Android firmware images on a compatible Android phone, including selected recovery ZIP, Odin, factory-image, system image and GSI formats.

Download Android APK ↗ View source code ↗ Firmware compatibility forum ↗
Important: AEmulator is a native Android application, not a browser app. GitHub Pages cannot execute its Android emulator engine inside this website. Use the APK on a compatible Android phone.

Requirements

  • Android 8.0 or later
  • 64-bit ARM (arm64-v8a) phone
  • About 1–3 GB free space per firmware image
  • Recent Snapdragon, Dimensity or Tensor chip recommended

Quick start

  • Open the official releases page and download the APK.
  • Install it on a compatible Android phone.
  • Choose “Add firmware” and select a firmware file you own or are authorized to use.
  • Start the virtual system and check the project forum for compatibility notes.

Firmware support varies by device and file format. AEmulator does not mean every ZIP will boot; check the official project documentation and compatibility notes before trying a ROM.
