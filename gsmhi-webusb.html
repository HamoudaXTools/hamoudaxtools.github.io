GSMHi WebUSB

صفحة اتصال مستقلة للموقع. جرّب فحص توافق المتصفح واختيار جهاز USB، أو افتح نسخة GSMHi الأصلية في تبويب مستقل. تشغيلها داخل iframe كان ممكن يمنع صلاحية USB، لذلك لم نعد نعتمد على iframe.

فتح أداة GSMHi الأصلية ↗

حالة الاتصال

في انتظار اختيار الجهاز
وصّل الهاتف بكابل بيانات وافتح قفل الشاشة قبل التجربة.
مهم: ظهور جهاز USB لا يعني أن المتصفح يدعم MTP أو أوامر ADB أو التفليش.
جاهز للفحص.

قبل الاتصال

  • افتح الصفحة المنشورة عبر HTTPS.
  • استخدم Chrome أو Edge حديثًا على الكمبيوتر.
  • استخدم كابل USB يدعم نقل البيانات، وليس الشحن فقط.
  • لأوامر ADB، فعّل USB debugging ووافق على رسالة الثقة على الهاتف عند الحاجة.
لم يتم تضمين ملفات GSMHi الأصلية داخل ZIP لأن بيئة تجهيز الملف لا تستطيع الوصول إلى GitHub حاليًا. زر «فتح أداة GSMHi الأصلية» يفتح نسخة CDN مباشرة في تبويب مستقل، ويحتاج اتصال إنترنت. فحص USB الموجود هنا محلي ومستقل.
