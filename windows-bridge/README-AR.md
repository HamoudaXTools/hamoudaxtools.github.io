# Hamouda XTools Bridge (نموذج أولي)

## ماذا يفعل؟
- يعمل محليًا على Windows على `127.0.0.1:8765`.
- يعرض أجهزة Android التي تظهر في `adb devices -l` إذا كان Android Platform Tools مثبتًا.
- لا يقرأ الجهاز عبر MTP فقط، ولا ينفذ تفليشًا أو مسحًا أو كتابة أقسام.

## التشغيل
1. ثبّت Python 3.10 أو أحدث.
2. (اختياري للتشخيص المتقدم) ثبّت Android SDK Platform Tools وأضف `adb.exe` إلى PATH.
3. شغّل `python bridge.py`.
4. اختبر `http://127.0.0.1:8765/health` و`http://127.0.0.1:8765/devices` محليًا.
5. لعرض معلومات ADB، يجب تفعيل USB debugging وموافقة المستخدم على رسالة RSA في الهاتف. هذا منفصل عن MTP.

## قيود الأمان
- النموذج محلي ومحدود للاستعلامات فقط، ولا يحتوي على endpoints لتنفيذ أوامر عشوائية.
- لا تفتح المنفذ على الشبكة العامة ولا تضف أوامر تفليش إلى الخادم دون تحقق من المستخدم وصلاحيات واضحة.
- متصفحات الويب قد تمنع الاتصالات إلى localhost بسبب Private Network Access/CORS؛ في الإنتاج الأفضل بناء تطبيق Bridge موقّع أو Native Messaging Host، مع origin allowlist وتوثيق محلي.
- دعم MTP في المتصفحات غير موحد؛ واجهة Connect Device في الموقع توضح هذا القيد.
