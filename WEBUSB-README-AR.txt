Hamouda XTools — Web Tools Lab

تمت إضافة صفحة web-tools.html وربطها من الصفحة الرئيسية، وتحتوي على روابط المشاريع التي تم الاتفاق عليها:
1. GSMHi WebUSB Tool
2. Web ADB
3. HTML QR Code Scanner
4. Android ADB Toolkit
5. PyOdin Web

ملاحظات:
- تمت إضافة صفحة فهرس/تشغيل وروابط إلى الأصول المنشورة والمستودعات الأصلية.
- لم يتم نسخ السورس الكامل للمشاريع الخارجية إلى المستودع؛ بيئة تجهيز الملف لا تستطيع الوصول إلى GitHub لتنزيل جميع ملفات المصدر واعتمادياتها.
- Web ADB وGSMHi وQR Scanner لها روابط تشغيل مباشرة معروفة. Android ADB Toolkit يحتاج غالبًا إعدادًا محليًا وخادمًا، وPyOdin Web مرتبط بالسورس والتعليمات فقط لتجنب رابط تشغيل غير متحقق منه.
- GitHub Pages يستضيف ملفات ثابتة فقط؛ لا يشغّل خوادم Python/Node ولا يضمن عمل كل وظائف USB أو التفليش.
- راجع تراخيص كل مشروع قبل دمج أو إعادة توزيع ملفات المصدر.
