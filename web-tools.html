معمل أدوات الويب

مكان واحد للوصول إلى سورسات وأدوات الويب التي اخترناها لـ Hamouda XTools. افتح الأداة المنشورة إن كانت متاحة، أو راجع المستودع الأصلي للحصول على السورس والتعليمات.

قبل الاستخدام: أدوات USB تحتاج غالبًا إلى كمبيوتر ومتصفح Chrome أو Edge واتصال HTTPS. بعض المشاريع تحتاج خادمًا محليًا أو بناءً باستخدام Node.js، لذلك لا تعمل جميعها بمجرد رفع ملفاتها إلى GitHub Pages. تأكد من هوية الجهاز وخذ نسخة احتياطية قبل أي تغيير أو تفليش.

متطلبات عامة

  • للاتصال عبر WebUSB: Chrome أو Edge على جهاز كمبيوتر، وموقع HTTPS.
  • فعّل USB debugging فقط عند الحاجة، ولا توافق على طلبات غير معروفة.
  • عمليات التفليش أو تعديل النظام قد تمسح البيانات أو تعطل الجهاز؛ استخدم ملفات مطابقة تمامًا للموديل وخذ نسخة احتياطية.
  • الأدوات الخارجية تظل تحت إدارة مطوريها. راجع الترخيص والملفات الأصلية قبل إعادة توزيع السورس أو دمجه.
